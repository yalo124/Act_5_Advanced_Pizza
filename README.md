## Clone Repository to your local device
Optional lang ito kung gusto niyo i-try ang program ng ibang groupmates natin.\
<br>
How to clone repository:
1. Open an empty IDE
2. Go to the terminal. Type this: git clone https://github.com/yalo124/Act_5_Advanced_Pizza.git
3. When done, type git checkout <branch_name>
   
Note:
1. Don't push anything to any branches because it will affect the GitHub repository if I do something
2. Don't do a pull request
3. Don't do a merge
4. To put it simply, don't do anything that will affect the GitHub repository.
